# Portfolio Website

This is a simple personal portfolio website created using HTML and CSS. The project consists of two pages: a Home page and a Contact page. It was developed to practice the fundamentals of web development, including page structure, navigation, styling, and layout design.

## Features

* Home page with personal introduction
* Contact page for displaying contact information
* Navigation between pages
* Basic CSS styling

## Technologies Used
